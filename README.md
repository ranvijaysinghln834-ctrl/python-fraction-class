
# Python Fraction Class

A beginner-friendly Python project demonstrating
Object-Oriented Programming (OOP) and operator overloading.
(In python we dont have function datatype so, we create it own datatype)

## Features
- Fraction addition
- Fraction subtraction
- Fraction multiplication
- Fraction division
- Custom string representation using `__str__`

## Concepts Used
- Classes and objects
- Constructors (`__init__`)
- Dunder methods
- Operator overloading

## Run the Project

```bash
python fraction.py
```

## Example Output

```text
Addition: 10/8
Subtraction: 2/8
Multiplication: 3/8
Division: 6/4
```
